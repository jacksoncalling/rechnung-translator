# output/

Where finished invoices land, one self-contained `.html` file per run. Older `.md` files are results from before the HTML output contract.

Nothing here is hand-edited to move the pipeline forward: the invoice is generated, a person reads it, and only then is it numbered in the register and sent. Open the HTML in a browser to print it or save it as PDF. Its Quellennachweis is available on screen and omitted from the printed page.
