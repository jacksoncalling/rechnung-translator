# input/belege/

Belege als Foto, Scan oder PDF. Eine Datei pro Beleg. Der Übersetzer liest sie direkt (Claude-Vision), du transkribierst nichts. Gelesen wird nach `../../reference/beleg-lesen.md`: nur was klar lesbar ist, keine geratene Ziffer.

- **Benennung:** `beleg-<haendler>-<datum>.<jpg|png|pdf>`
- **Öffentliches Repo:** nur klar gekennzeichnete, synthetische Musterbelege. Niemals einen echten Beleg eines echten Händlers oder Kunden committen.

Der Musterbeleg hier ist ein synthetischer Testbeleg, sichtbar als `MUSTERBELEG` gekennzeichnet. Ein echtes Handyfoto einer echten Quittung funktioniert genauso.
